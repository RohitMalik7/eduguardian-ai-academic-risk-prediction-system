# EduGuardian AI
### AI Academic Risk Prediction & Early Intervention System
**ICT304 – AI System Development (Final Project)**
Murdoch University – School of Information Technology

---

## Project Overview

EduGuardian AI is a **full-stack AI-powered academic risk prediction system** designed to identify at-risk students early and support timely intervention.

The system combines:
- **Deterministic academic risk analysis** (quiz trends + assignment performance)
- **Machine Learning prediction** (trained on multi-dataset student data)
- **Hybrid decision engine** for final risk classification

The goal is to provide **interpretable, data-driven insights** for both staff and students.

---

## System Architecture

EduGuardian AI uses a **hybrid AI pipeline**:

**1. Deterministic Risk Engine**
- Quiz trend analysis (increasing / decreasing performance)
- Assignment-based risk scoring
- Produces interpretable academic risk indicators

**2. Machine Learning Model**
- Trained using 5 datasets (Kaggle + OULAD)
- Models tested: Logistic Regression, Random Forest, XGBoost
- Best model selected based on **F1-score for at-risk class**

**3. Hybrid Decision Layer**
- Combines ML probability + deterministic score
- Default configuration:
  - ML Weight: 0.55
  - Engine Weight: 0.45
- Runtime configurable via Staff Portal

## Key Features

### Staff Portal

- Configure assessment weights

- Run AI model (with configurable parameters)
- View cohort-level risk insights
- Export reports (PDF / JSON)

### Student Portal
- Enrol in active units
- Submit quiz and assignment scores
- View AI-generated risk status
- Download personalised risk report

## Installation & Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Seed the database

```bash
python database/seed_db.py
```

### 3. Run the application

```bash
python run.py
```

Open in browser: **http://127.0.0.1:5000**

## How to Use the System

1. Log in as **staff**
2. Activate ICT304 or create and configure additional units
3. Add or enrol students.
4. Import or manage student assessment data through the Staff Portal
5. Run the AI model from the dashboard (with configurable parameters)
6. View cohort-level risk results and individual student insights
7. Export reports in PDF, CSV, or JSON formats

---

### Student Workflow

1. Log in as **student**
2. Enrol in available active units
3. View your academic performance and AI-generated risk status
4. Download your personalised risk report after the model has been executed by staff

## Pre-Training the AI Model (Optional)

The model trains automatically the first time staff click **Run Model**. To pre-train manually:

```bash
python src/preprocess.py
python src/train_model.py
python src/evaluate_model.py
```

Evaluation plots and summary are saved to `reports/`.
